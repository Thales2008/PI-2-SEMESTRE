# Savi Mare Sociale

A **Savi Mare Sociale** é uma loja especializada em moda masculina social e acessórios, com foco em produtos para casamentos, eventos formais e ocasiões especiais.

Seu catálogo oferece diferentes opções de gravatas masculinas Slim, comercializadas individualmente ou em kits, com variedade de cores e quantidades para atender tanto clientes individuais quanto grupos de padrinhos.

## Produtos

Entre os principais produtos comercializados estão:

- **Gravatas Slim:** modelos masculinos para ocasiões sociais e formais.
- **Kits para padrinhos:** conjuntos de gravatas para padronização visual em casamentos.
- **Variedade de cores:** azul-marinho, azul serenity, cinza, lilás, marsala, bordô, verde-oliva, terracota, bege, preto e outras tonalidades.
- **Kits em diferentes quantidades:** opções para atender diferentes necessidades e tamanhos de grupos.
- **Camisas sociais masculinas:** modelos Slim Fit.

## Sobre a marca

A Savi Mare Sociale busca atender consumidores que procuram acessórios masculinos para ocasiões especiais, oferecendo variedade de modelos, cores e opções de compra.

Seu catálogo atende especialmente pessoas que desejam coordenar a aparência dos padrinhos de casamento e complementar o vestuário social.
